# 🚗 Smart Parking

## 📚 Project Overview

**Smart Parking** is a final year project aimed at solving the problem of parking in congested urban areas by providing a smart and efficient parking management system. 

The system includes a web and mobile application that allows users to find and reserve parking spaces, as well as an embedded system to manage the parking infrastructure. The project was realized using agile methodologies to ensure a high-quality, efficient, and cost-effective solution.

## 🛠️ Technologies Used

- **🌐 Web Application:** Developed using HTML5, CSS, and JavaScript for the frontend, and Node.js with MongoDB for the backend.
- **📱 Mobile Application:** Built using Cordova Apache to create hybrid mobile apps for both iOS and Android platforms.
- **⚙️ Embedded System:** Managed by an ESP32 microcontroller to control sensors and actuators, ensuring real-time parking management.
- **💻 Database:** MongoDB was used for storing and managing data in a NoSQL format, communicating with the backend via REST API.

## 🚀 Features

- **Real-time Parking Management:** The system automatically updates the availability of parking spaces using sensors and an embedded system.
- **User Management:** Admins can manage users, view parking reservations, and monitor system performance.
- **Parking Reservation:** Users can find and reserve parking spaces via the web or mobile app, with special features for electric vehicles and shared cars.
- **Revenue Tracking:** The admin interface allows for easy monitoring of revenue generated from parking reservations.

## 📈 System Architecture

The project is divided into three main components:

1. **Web & Mobile Applications:** User-facing platforms for finding, reserving, and managing parking spaces.
2. **Embedded System:** Handles the real-time management of parking spaces, using sensors to detect availability.
3. **Admin Dashboard:** A powerful backend interface for managing the entire system, including user management, revenue tracking, and system settings.

## 📊 Project Planning

The project was developed in three sprints following the Scrum methodology:

- **Sprint 1:** User authentication and admin management.
- **Sprint 2:** Parking management, including adding, editing, and deleting parking spaces.
- **Sprint 3:** Development of the embedded system and integration with the mobile and web applications.
